# UI/UX レビュー

## 実施
- 幅320/375/768pxで16画面の横スクロール検査（合格）。
- axe-core による WCAG 2.x A/AA 検査（light/dark・合格）。
- 95%チャレンジ：初見/復習/累計を分離表示、「95%は目標で保証ではない」を明記、2級学科以外では専用メッセージ。
- 難易度・「オリジナル」バッジを問題画面に表示（公式問題との誤認防止）。
- 複数小問（語群補充）は全解答欄に答えて「解答する」で確定。
