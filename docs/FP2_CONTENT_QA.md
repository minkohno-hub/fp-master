# FP2 コンテンツ品質保証

## 検証手順（オリジナル問題）
1. 各肢に根拠引用を付与し、`check_batch.py` が出典ページ原文（空白除去の部分一致）と照合。不一致 0 が必須。
2. `fporig` の検証：正解がちょうど1つ／4肢が互いに異なる／問題文が「か。」で終わる／各肢の解説 40字以上／他肢番号を参照しない。
3. 敵対的レビュー（別エージェント）：真偽の再検証、計算の独立再計算、重複、難易度の正直さ、時点依存（2026-04-01 以降の改正・年度別金額）、業界団体のみの根拠。
4. `build_content.py` がネットワークで根拠を再照合し verified／draft を決定。`vitest`（データ検証）で全問の構造・解説・ID 一意性を確認。

## 結果（実測）
- 解説 verified：オリジナル 553／553、全選択肢解説 553／553。
- 照合済み根拠（用語・カード・解説の合計）：850、要確認 580（既存の draft 項目。FP2 の新規問題は全て verified）。
- 隔離（quarantined）0、重複 0、vitest 112 passed、tsc エラーなし。
