# 開発計画

更新日: 2026-10-21（Asia/Tokyo）

FP Masterは日本FP協会のFP2級・3級（学科・資産設計提案業務）の個人学習アプリを目指す。95%は学習目標。正式合格基準、初見成績、復習成績、教材網羅性、本人の習得率を混同しない。

## 品質の順序

教材の正確性 → 公式範囲 → 学習効率 → UI/UX → 安定性 → データ保全 → セキュリティ → 保守性 → 速度。各段階の到達を実測・原典照合で判断する。教材調査と機能開発を並行し、未確認教材で実動作を装わない。

## フェーズと終了条件

| 段階 | 実施内容 | 終了条件 | 現状 |
| --- | --- | --- | --- |
| 1 調査・設計 | 所有者確認、公式制度・許諾・全論点、モデル、UX | 公式資料取得・仕様照合記録と教材公開方針 | リポジトリ確認済み、公式取得403で未完 |
| 2 中核 | 条件保存、5〜100問、採点、詳細解説、履歴、再開 | 検証済み公開可能教材で一連操作を実測 | 安全な基盤へ移行中、教材0件 |
| 3 定着 | 用語、カード、SM-2復習、ブックマーク、間違いノート | 問題と用語・カードが連動、保存・予定日検証 | 段階実装 |
| 4 高度対策 | 数値計算、4区分模試、分析、95%・計画 | 公式仕様と配分照合、計算・採点を検証 | 仕様未確認のため公式模試は保留 |
| 5 教材拡充 | 過去問・独自問題、例外、全解説、改正 | 全論点分母と各確認済み教材の対応照合 | 原典・許諾確認待ち |
| 6 UX | デザインシステム、dark、アクセシビリティ、性能 | 主要操作をスマホ/PCで実測、改善 | 中核実装と並行 |
| 7 総合QA | E2E、バックアップ、オフライン、Pages | 完成判定の各項目に検証証跡 | 未達、公開未実施 |

## 機能提供の原則

確認済み・公開可能な問題がなければ、演習は不足状態を示す。模擬試験の必要数、時間、配点は公式確認後に有効にする。予定だけの機能を完成扱いしない。作業停止時には `NEXT_ACTION.md` から再開できる形で差分と結果を保存する。

## 公開の条件

GitHub Pages向けの静的ビルドと手動デプロイ経路を用意する。公開URLはデプロイ後に実アクセスしてから記載する。許諾不明教材の公開、非公開情報の公開、追加費用を伴う作業は事前承認が必要。環境のドラフト保存はGitHub Pages公開を意味しない。
