## 方針
1. 公式過去問（FP協会公表）はそのまま。オリジナルは `source.kind: original` で UI に「オリジナル問題」と明示。
2. オリジナルは法令・公的ページの原文引用で真偽を裏づけた肢のみ。基準日 2026-04-01、基準日以降の改正・年度別金額に依存する問は作らない。
3. 作成→敵対的レビュー（別エージェントが真偽・重複・難易度・時点依存を検証し修正／削除）→再ビルド→tsc/vitest の順。レビューで削除・降格した問が多数あり（数合わせの水増しはしない）。
4. 実技（資産設計提案業務）は公式形式を維持。実技形式・非四択のオリジナルは別バッチ（j01/k01）で追加中（`FP2_NEXT_ACTION.md` 参照）。
