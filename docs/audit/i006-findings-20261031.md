## 3. 改善提案（J14 以降への反映事項）

1. **分野配分の是正を最優先**：J14 以降は B（リスク管理）・A（ライフプランニング）・C（金融資産運用）・E（不動産）のケースを優先し、D は新規 topic がない限り抑制する。目標感：D 比率を 53.8% から段階的に引き下げる。
2. **レベル校正ルールの明文化**：Lv5 の付与条件（例：3段階以上の連鎖計算、または複数制度の複合判断＋資料2点以上）を AUTHORING 側の基準として定義し、J14 以降に適用する。既存60件の一括再判定は行わず、サンプル再評価（本監査の深読み方式）で乖離を継続監視する。
3. **重複管理の徹底**：同一 topic で3件目以降を作成する場合は、バッチ冒頭 docstring に「先行ケースとの差分（角度・計算対象・資料形式）」を小問単位で明記する。j13-04 型の「新規小問が過半未満」のケースは新規バッチの題材にしない。
4. **計算密度の目安**：Lv5 ケースは NUM 2問以上を目安とする。手続系テーマ（J12 型）では、SEL を組合せ・複合条件形式にして判断負荷を担保する。
5. **ケース内命題の重複禁止**：NUM で問うた命題を TF で言い換えて同一ケース内で再出題しない（j01-04 型の回避）。
6. **J01 の底上げ**：j01 の Lv2〜4 テーマ（NISA・国民年金・地震保険等）について、高難度版を J14 以降で追加するスパイラル方式を A・B 分野にも広げる。
7. **topic キー借用の記録**：専用キーがない論点では借用理由をケースの memo に残し、カバー集計時に注記できるようにする。
