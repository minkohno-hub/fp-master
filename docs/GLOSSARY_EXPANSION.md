## 追加方針
- 原稿：`scripts/content/glossary_more_src.py`（A〜F の `MORE_*`）。`build_content.py` が `TERMS` に結合して `glossary.json` を生成する。
- 追加語の表記が既存語・他の追加語と重複すると、自動リンクが曖昧になる。`tests/unit/termlink.test.ts` が重複を検出する（実際に「自筆証書遺言」の衝突を検出し、別名から外した）。
- 毎回 `python3 -I scripts/content/build_content.py`（ネットワーク照合）→ `npx vitest run`。

## 第2弾（2026-10-31、Wonder側で実施）

ユーザー仕様（用語集の大幅拡充＋問題文リンクの自動連携）に基づき、基盤強化と6分野一括追加を実施した。

### 基盤
- 用語スキーマ拡張：`facts`（重要な数字・適用条件。年度・条件を明記したもののみ）／`cautions`（例外・注意点）／`compare`（類似用語との違い）／`topics`（シラバス細目キー）／`lawBaseDate`（全語に 2026-04-01）／`checkedAt` を追加。既存216語のIDは不変（ID変更は学習状態・URLを壊すため禁止）。
- `question-terms.json` を自動生成化：手動登録 ∪ 自動検出（問題文・小問・資料＋解説文を対象に最長一致マッチ。根拠引用文・出典は対象外）。
- 用語リンクの適用範囲を計算トレーニング（設問・手順・計算式の説明）とアプリ内ガイド（説明書）へ拡大。模擬試験の実施中は用語ポップアップを無効化（解答漏洩防止）。ポップアップに お気に入り切替・facts・具体例・詳細ページへの導線を追加し、デスクトップでは右サイドパネル化。用語集に かな正規化検索・重要度フィルタ・級フィルタを追加。単問ページは回答下書きを保持し、用語詳細から「問題に戻る」で復元。お気に入り用語の暗記カードモードを追加。
- 基礎控除の監査：国税庁 No.1199 の現行表と照合し、オリジナル問題・用語とも誤りなし（高所得側の逓減表は全年度不変で、問題はその範囲のみを扱う）。
