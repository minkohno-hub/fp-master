# FP Master

FP2級・3級の学習Webアプリ基盤。React / TypeScript / Vite を使用し、PC・iPhone向けのレスポンシブUIを備えます。

## 開発

Node.js 24 / npm 11 を推奨します。

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dev` は5173、`preview` は4173ポートを使用します。追加の環境変数・APIキー・バックエンドは不要です。CIでも型チェック、テスト、本番ビルドを実行します。

## 現在の機能

- FP2級・3級のコース切替、6分野のサンプル演習
- 計算問題のみの演習、回答と詳細解説
- 回答履歴・正答率の表示、直近で間違えた問題の復習
- バージョン付きlocalStorageへの保存、読み込み・保存失敗の通知
- キーボード操作、ラジオボタン、本文スキップ、回答結果の読み上げ通知

**教材は各級共通の基礎確認サンプル6問です。公式問題ではなく、試験範囲を網羅していません。目標正答率95%以上は学習上の目標であり、達成・合格を保証しません。** 模擬試験は準備中です。

履歴はブラウザ・端末ごとに保存されます。サーバー同期・アカウント機能はなく、ブラウザのデータ削除で失われます。壊れた履歴は上書きせず通知します。保存できない場合も現在の画面内では学習を続けられます。

## 構成と拡張

- `src/domain/learning.ts`: 級・分野・問題・回答履歴の型、統計、復習対象・出題の純粋関数
- `src/data/questions.ts`: ID・級・分野・種別・選択肢・正解・解説・基準日を持つ教材データ
- `src/features/history.ts`: 保存境界と保存データの検証
- `src/App.tsx`: ダッシュボード・演習・履歴・復習の画面とセッション管理
- `src/styles.css`: モバイル下部ナビ、PCサイドバー、レスポンシブレイアウト

教材の追加は安定した一意IDを用い、問題・正解・解説・法令基準日を専門家が確認してください。既存IDの意味を変える場合は履歴の移行が必要です。公式範囲の網羅状況は、将来、分野別の出題範囲メタデータと対応付けて管理します。

模擬試験は問題データと回答履歴を再利用し、制限時間・出題配分・採点・途中再開を持つ独立したセッション機能として追加できます。学習履歴のサーバー同期は保存境界をリポジトリ層へ置き換え、認証・競合解決・データ移行を追加します。95%目標の進捗は今後、単純な累計正答率とは別に分野別・期間別・未回答範囲を評価する設計が必要です。

## 品質確認

Vitest / Testing Libraryで、級・分野フィルタ、計算・復習対象、最新回答による復習解消、教材整合性、保存・復元・破損・容量不足、回答から解説・履歴・復習までの操作を検証します。

画面確認はデスクトップ1440px、iPhone相当390px、小画面320pxを対象にします。Chromiumでのエミュレーションは実機Safari検証を代替しません。リリース前には実機Safariでタッチ操作・文字サイズ・セーフエリアを確認してください。
