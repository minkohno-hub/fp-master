# FP Master

日本FP協会のFP2級・3級（学科／資産設計提案業務）を対象とする個人学習アプリです。React、TypeScript、Viteを使用し、スマートフォンとPCで操作できる画面を備えます。GitHub Pages配信を想定したPWAです。

**開発中です。公開・原典確認済みの教材は現在0問です。** 旧デモ12問は根拠・法令基準日・Web公開条件が確認できないため本番出題から隔離しています。公式試験範囲の網羅率も、公式の全論点を確認できていないため算定できません。模擬試験は現行仕様と十分な教材を確認するまで開始できません。95%は個人の学習目標で、合格や試験での達成を保証しません。

## 開発と検証

Node.js 24、npm 11を推奨します。

```sh
npm ci
npm run dev
```

Viteの`base`は`/fp-master/`です。開発時は`http://localhost:5173/fp-master/`、本番プレビューは`npm run preview`後に`http://localhost:4173/fp-master/`で開きます。

```sh
npm run lint
npm run typecheck
npm test
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
npm audit
```

`/usr/bin/chromium`はこのクラウド環境のE2E向けです。他の環境ではPlaywrightが管理するブラウザを利用してください。E2Eの合成問題は`tests/fixture.html`を使い、通常の本番ビルドには含めません。CIはLint・型チェック・単体/結合テスト・本番ビルド・E2Eを実行します。Pagesデプロイは手動ワークフローです。URLが実際に配信されるまでは公開済みと扱いません。

## 使える基盤

- 2級・3級、学科・日本FP協会実技の切替と6分野の出題条件
- 知識問題だけの通常演習、計算問題だけの計算トレーニング、条件保存、指定数不足の通知
- 1問ずつの採点、3段階の解説、ブックマーク、理解度自己評価、間違いノート、中断と再開
- BigIntを使う小数計算・単利・複利等の処理と、数値回答・端数処理の基盤
- SM-2を参考にした復習予定、初見・直近・復習・分野・難易度別の分析
- 暫定44論点の不足表。公式範囲との照合が終わるまで公式網羅率を表示しません
- 用語集・暗記カードの画面と保存基盤。カードは自己評価に応じて復習予定を調整し、期限が来たカードを抽出できます。確認済み用語は現在0件です
- 日別学習配分、ライト/ダーク表示、オフライン起動、IndexedDB保存
- バージョンと重複・競合を検証するJSONバックアップ／復元。既存データを削除せず、失敗時は取り消します
- 4区分の模試仕様・採点・配分・時間制限のドメインロジック。現行公式仕様未確認のためUIからは開始できません

履歴は端末のブラウザ内に保存します。以前のlocalStorage履歴は非破壊で移行します。端末間同期には対応していません。別端末に移るときは設定からJSONを保存・復元してください。

## 教材を追加する前に

`src/domain/curriculum.ts`の`MaterialQuestion`に、級・試験区分・分野/論点・形式/難易度・正答・選択肢別解説・原典・法令基準日・確認日・利用条件・データ版を登録します。`src/content/audit.ts`で候補の構造と公開条件を監査できます。原典本文・正答・解説・現行制度・Web公開条件の照合は編集者が行います。スキーマ検査は事実確認を代替しません。旧サンプルは`src/data/quarantine.ts`にあり、本番カタログへ混ぜないでください。

原典・法改正の記録は`src/content/legal.ts`、試験仕様は`src/data/examSpecifications.ts`、収録教材は`src/data/catalog.ts`で管理します。教材IDやデータ版を変更するときは履歴と模試の互換性を検討してください。現行公式資料と利用条件へのアクセスは環境のネットワーク設定に依存します。未確認項目と再開手順は[開発計画](docs/MASTER_PLAN.md)、[既知の制約](docs/KNOWN_ISSUES.md)、[次の作業](docs/NEXT_ACTION.md)を参照してください。
